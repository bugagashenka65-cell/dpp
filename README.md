# Лендинг «Халва зарплатная»

Одностраничный сайт (лендинг), свёрстанный по постеру «Карта рассрочки Халва зарплатная» от Совкомбанка.

## Структура проекта

```
site/
├── index.html        ← главная страница (сам лендинг)
└── images/
    ├── 1.png         ← карта (блок «Бесплатно» внизу)
    ├── 2.png         ← верхний оранжевый блок «Немного о карте»
    ├── 3.png         ← нижний оранжевый блок «Немного о карте»
    ├── 4.png         ← карта в шапке (вверху)
    ├── 5.png         ← чип колонки «Без подписки» (кэшбэк)
    └── 6.png         ← чип колонки «С подпиской» (кэшбэк)
```

> **Важно:** картинки лежат в папке `images/` рядом с `index.html` и подключаются относительными путями (`images/1.png`), поэтому после загрузки в GitHub они будут работать автоматически.

# Пошаговая инструкция: как выложить на GitHub и открыть сайт

## Способ 1. Git + терминал (рекомендуемый)

### 1. Создайте репозиторий на GitHub
1. Зайдите на https://github.com и нажмите **«New repository»** (зелёная кнопка).
2. В поле **Repository name** введите имя, например `halva-zarplatnaya`.
3. Выберите **Public** (будет бесплатный хостинг на GitHub Pages).
4. **НЕ** отмечайте «Add a README file» (чтобы не было конфликта). Нажмите **Create repository**.

### 2. Загрузите файлы через терминал
Откройте терминал/КОМАНДНУЮ СТРОКУ на компьютере и выполните по порядку:

```bash
# 1) Перейдите в папку с сайтом (замените путь на свой)
cd путь/к/site

# 2) Создайте репозиторий git в папке
git init

# 3) Добавьте все файлы (index.html + папку images) в отслеживание
git add .

# 4) Сделайте первый коммит
git commit -m "Лендинг Халва зарплатная"

# 5) Подключите удалённый репозиторий (вставьте СВОЙ адрес из GitHub, без фигурных скобок)
git branch -M main
git remote add origin https://github.com/ВАШЕ_ИМЯ/halva-zarplatnaya.git

# 6) Отправьте файлы на GitHub (введёте логин и пароль/токен)
git push -u origin main
```

### 3. Включите GitHub Pages (бесплатный хостинг)
1. Откройте репозиторий на GitHub.
2. Зайдите в **Settings** → **Pages** (в меню слева).
3. В разделе **Branch** выберите ветку `main` и нажмите **Save**.
4. Подождите 1–2 минуты, пока сайт соберётся.
5. Готово! Сайт будет доступен по адресу:
   ```
   https://ВАШЕ_ИМЯ.github.io/halva-zarplatnaya/
   ```
   (если репозиторий называется `halva-zarplatnaya`).

## Способ 2. Загрузка без терминала (через сайт GitHub)

Если у вас нет `git` на компьютере:

1. Создайте репозиторий, как в шаге 1 выше.
2. На странице нового репозитория нажмите **«uploading an existing file»** (добавить файл).
3. Перетащите туда файл `index.html`.
4. Затем создайте папку `images` отдельной кнопкой:
   - жмите **Add file** → **Create new file**,
   - в поле имени введите `images/1.png` → но так по одному неудобно.
   **Лучше так:** в режиме загрузки нажмите `images/` в поле папки — GitHub сам предложит создать папку, куда можно перетащить все 6 файлов `1.png … 6.png` разом.
5. Нажмите **Commit changes**.

# Проверка, что картинки рабочие

1. Откройте сайт по ссылке `https://ВАШЕ_ИМЯ.github.io/halva-zarplatnaya/`.
2. Картинки должны отображаться. Если нет — нажмите **F12** (инструменты разработчика) → вкладка **Network**, найдите ошибки `404`.
3. Причина ошибок — обычно картинки не загрузились в репозиторий. Убедитесь, что папка `images/` со всеми 6 PNG лежит в корне репозитория **рядом с `index.html`** (в той же ветке `main`).

## Как открыть локально (проверка до публикации)

Просто откройте файл `site/index.html` двойным кликом в браузере. Все картинки и шрифты подтянутся автоматически (интернет нужен только для шрифтов Google Fonts).
